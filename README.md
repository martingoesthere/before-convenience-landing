# Before Convenience — Landing Page

A simple React + Vite landing page for the Before Convenience YouTube channel.

## Run it
1. Install Node.js (version 18 or newer) from https://nodejs.org
2. Open a terminal in this folder and run:
   npm install
   npm run dev
3. Open the address it shows (usually http://localhost:5173).

## Edit it
- Text, topics and featured episodes: src/App.jsx (the THEMES and EPISODES lists at the top)
- Colors and fonts: the :root section at the top of src/App.css
- Logo and banner: replace the files in public/images (keep the same names)

## Publish it
Run `npm run build`. Upload the `dist` folder to any static host
(Netlify, Vercel, GitHub Pages, Cloudflare Pages).
